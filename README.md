# CorineKit Fetcher

![CorineKit Fetcher](Fetcher/FetcherIcon.ico)

## 简介

CorineKit Fetcher 是一款基于 WPF 的媒体抽选工具，专门用于随机浏览文件夹里的图片和视频。图片支持 JPG、PNG、BMP、TIFF、WEBP，GIF 会直接播放动画，视频支持 MP4、MKV、WEBM 等常见容器。

## 功能特性

- **随机抽选**: 按空格键随机抽选图片。采用全覆盖遍历算法——以"轮"为单位发放，一轮之内每张图片恰好被抽到一次，不重复也不遗漏；子目录按剩余比例轮转，深层小目录不会被大目录长期盖住；同一目录内相邻两次抽选保持足够跳跃距离（形如 4→8→1→5→2，而不是 1→2→3→4）
- **动图与视频播放**: GIF 按文件内记录的帧间隔逐帧播放并尊重循环次数，视频走系统 Media Foundation 硬解播放、播完自动重头再放；P 键暂停/继续，缩放平移与图片完全一致
- **画布缩放平移**: 右键按住滚滚轮即可以指针为中心缩放（缩放的唯一入口），右键或中键按住拖拽即可平移，右键单击复位
- **滚轮分区切图**: 滚轮按悬停位置分成两区——面包屑上 / 其他区域，一区随机切换缓存图片、一区按目录顺序切换，哪一区是随机可以在设置面板里对调（会保存）；悬停在展开的设置面板上时滚轮不切图；圆点指示器常驻窗口底部显示当前缓存位置
- **图片缓存**: 可调节缓存大小，快速切换已浏览图片
- **多语言支持**: 中文、英文、日文三种语言
- **主题切换**: 6种预设主题背景（白色、深色、深紫色、深蓝色、军绿色、深棕色）
- **路径导航**: 快速导航到任意父级目录（盘符段不可点击）
- **键盘快捷键**:
  - ←/→ 方向键：前后切换缓存图片
  - ↑/↓ 方向键：按顺序切换图片
  - 空格键：随机抽选图片
  - Tab 键：显示/隐藏设置面板
  - F 键：重新适配窗口并复位画布
  - P 键：暂停 / 继续当前 GIF 或视频（静态图片上是空操作）
  - 双击/中键：打开当前图片
- **鼠标操作**:
  - 滚轮（悬停面包屑）：默认随机切换缓存图片
  - 滚轮（悬停其他区域）：默认按目录顺序前后切换图片
  - 滚轮（悬停展开的设置面板）：不切图，交给面板里的滑块和下拉框
  - 右键按住 + 滚轮：以鼠标指针为中心缩放画布（缩放的唯一入口）
  - 右键按住 + 拖拽：平移画布
  - 右键单击：按当前窗口尺寸重新适配并复位画布（等同 F 键）
  - 中键按住 + 拖拽：平移画布
  - 中键单击：图片上打开当前图片，面包屑上在资源管理器中打开该目录
  - 左键拖拽：把当前图片拖放到其他程序
  - 右键单击面包屑：列出同级目录（仅含有受支持媒体文件的）
- **会话恢复**: 关闭后自动记住上次浏览的文件夹
- **拖放支持**: 直接将文件夹拖入窗口打开

## 使用方法

1. 启动程序后，将包含图片或视频的文件夹拖入窗口
2. 滚动滚轮切换图片：默认悬停面包屑时随机切换、悬停其他区域时按目录顺序切换，也可以用方向键
3. 按空格键随机抽选新图片
4. 按 Tab 键打开设置面板，可调节：
   - 缓存页数
   - 背景颜色主题
   - 界面语言
   - 滚轮随机区（悬停面包屑时随机 / 悬停其他区域时随机）

## 支持的媒体格式

**图片**：JPG / JPEG、PNG、BMP、TIFF、WEBP

**动图**：GIF（按文件内记录的帧间隔逐帧播放，尊重 NETSCAPE 循环次数）

**视频**：MP4 / M4V、MOV、MKV、WEBM、AVI、WMV、MPG / MPEG、3GP

解码全部交给 Windows 自带的 WIC 与 Media Foundation，程序本身不打包任何解码器，所以实际能否显示取决于系统装了哪些扩展：

- **WEBP** 需要 Microsoft Store 的「WebP 图像扩展」(`Microsoft.WebpImageExtension`)
- **WEBM** 需要「Web Media Extensions」；编码是 VP9 / AV1 时还要装对应的视频扩展
- 缺少解码器时不会弹错误框，程序会跳过该文件继续抽选，并在本次会话内提示一次应该装什么；连续 30 个文件都失败时会停下来告知大概是缺解码器

> WEBM 的实现细节：WPF 的 `MediaElement` 走 Media Foundation 老管线，它按**扩展名**查字节流处理器，而 Windows 内置的表里有 `.mkv` 却没有 `.webm`。所以程序会在同卷的隐藏缓存目录里给 `.webm` 建一个同内容的 `.mkv` NTFS 硬链接（只写元数据，不复制数据）喂给 `MediaElement`；切换媒体时删除替身，启动时再清扫一次上次异常退出的残留，源文件永远不会被动到。

## 项目结构

```
CorineKit_Fetcher/
├── Fetcher.sln           # 解决方案文件
├── Fetcher/
│   ├── Fetcher.csproj    # 项目文件
│   ├── App.xaml          # 应用入口
│   ├── App.xaml.cs       # 启动时清理遗留的视频替身文件
│   ├── MainWindow.xaml   # 主窗口（图片层 + 视频层）
│   ├── MainWindow.xaml.cs
│   ├── MediaFormats.cs          # 受支持扩展名的唯一清单与类型判定
│   ├── GifPlayer.cs             # GIF 逐帧播放引擎（帧间隔 + 循环次数）
│   ├── VideoSourceResolver.cs   # webm → mkv 硬链接替身管理
│   ├── RandomTraversalEngine.cs # 全覆盖随机遍历引擎（分层牌堆 + 高跳跃洗牌）
│   ├── CanvasViewState.cs       # 画布缩放/平移的纯数学部分
│   ├── PathBreadcrumb.cs        # 面包屑路径分段
│   ├── Settings.cs       # 设置管理
│   ├── LanguageResources.cs # 多语言资源
│   └── FetcherIcon.ico   # 程序图标
└── README.md
```

## 版本历史

### v1.0.3 (2026-09-26)

- 重写随机抽选算法为全覆盖遍历：以"轮"为单位发放，一轮内每张图片恰好被抽到一次，不重复也不遗漏（旧算法在 100 张图中抽 100 次平均会漏掉约 37 张）
- 子目录按剩余比例轮转，深层小目录不再被大目录长期盖住；同目录内相邻两次抽选保持足够跳跃距离

- 面包屑盘符段不再可点击，避免误触扫描整个磁盘
- 修复面包屑路径拼接产生的驱动器相对路径问题（`C:Users` 型），改为从盘符根开始拼接
- 修复适配窗口缩放按窗口外框（含标题栏）计算导致图片略微溢出的问题
- 修复平移画布后"恢复上次会话"按钮从图片下方露出、且仍可被点击的问题
- 新增 F 键：按当前窗口尺寸重新适配并复位画布
