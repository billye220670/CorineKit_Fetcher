# CorineKit Fetcher

![CorineKit Fetcher](Fetcher/FetcherIcon.ico)

## 简介

CorineKit Fetcher 是一款基于 WPF 的图片抽选工具，专门用于随机浏览文件夹中的图片。支持多种图片格式，包括 JPG、PNG、BMP、GIF 等。

## 功能特性

- **随机抽选**: 按空格键随机抽选图片。采用全覆盖遍历算法——以"轮"为单位发放，一轮之内每张图片恰好被抽到一次，不重复也不遗漏；子目录按剩余比例轮转，深层小目录不会被大目录长期盖住；同一目录内相邻两次抽选保持足够跳跃距离（形如 4→8→1→5→2，而不是 1→2→3→4）
- **画布缩放平移**: 右键按住滚滚轮即可以指针为中心缩放（缩放的唯一入口），右键或中键按住拖拽即可平移，右键单击复位
- **滚轮分区切图**: 窗口纵向对半分——上半滚轮按目录顺序切图，下半滚轮切换缓存图片；圆点指示器常驻窗口底部显示当前缓存位置
- **图片缓存**: 可调节缓存大小，快速切换已浏览图片
- **多语言支持**: 中文、英文、日文三种语言
- **主题切换**: 6种预设主题背景（白色、深色、深紫色、深蓝色、军绿色、深棕色）
- **路径导航**: 快速导航到任意父级目录（盘符段不可点击）
- **键盘快捷键**:
  - ←/→ 方向键：前后切换缓存图片
  - ↑/↓ 方向键：按顺序切换图片
  - 空格键：随机抽选图片
  - Tab 键：显示/隐藏设置面板
  - F 键：重新适配窗口并复位画布
  - 双击/中键：打开当前图片
- **鼠标操作**:
  - 滚轮（窗口上半）：按目录顺序前后切换图片
  - 滚轮（窗口下半）：前后切换缓存图片
  - 右键按住 + 滚轮：以鼠标指针为中心缩放画布（缩放的唯一入口）
  - 右键按住 + 拖拽：平移画布
  - 右键单击：按当前窗口尺寸重新适配并复位画布（等同 F 键）
  - 中键按住 + 拖拽：平移画布
  - 中键单击：图片上打开当前图片，面包屑上在资源管理器中打开该目录
  - 左键拖拽：把当前图片拖放到其他程序
  - 右键单击面包屑：列出同级目录（仅含有图片的）
- **会话恢复**: 关闭后自动记住上次浏览的文件夹
- **拖放支持**: 直接将文件夹拖入窗口打开

## 使用方法

1. 启动程序后，将包含图片的文件夹拖入窗口
2. 把鼠标移到窗口底部的指示器区域后滚动滚轮，或用方向键切换图片
3. 按空格键随机抽选新图片
4. 按 Tab 键打开设置面板，可调节：
   - 缓存页数
   - 背景颜色主题
   - 界面语言

## 支持的图片格式

- JPG/JPEG
- PNG
- BMP
- GIF

## 项目结构

```
CorineKit_Fetcher/
├── Fetcher.sln           # 解决方案文件
├── Fetcher/
│   ├── Fetcher.csproj    # 项目文件
│   ├── App.xaml          # 应用入口
│   ├── App.xaml.cs
│   ├── MainWindow.xaml   # 主窗口
│   ├── MainWindow.xaml.cs
│   ├── RandomTraversalEngine.cs # 全覆盖随机遍历引擎（分层牌堆 + 高跳跃洗牌）
│   ├── CanvasViewState.cs       # 画布缩放/平移的纯数学部分
│   ├── PathBreadcrumb.cs        # 面包屑路径分段
│   ├── Settings.cs       # 设置管理
│   ├── LanguageResources.cs # 多语言资源
│   └── FetcherIcon.ico   # 程序图标
└── README.md
```

## 版本历史

### v1.0.3 (2026-09-26)

- 重写随机抽选算法为全覆盖遍历：以"轮"为单位发放，一轮内每张图片恰好被抽到一次，不重复也不遗漏（旧算法在 100 张图中抽 100 次平均会漏掉约 37 张）
- 子目录按剩余比例轮转，深层小目录不再被大目录长期盖住；同目录内相邻两次抽选保持足够跳跃距离
- 新增画布功能：右键按住 + 滚轮以鼠标指针为中心缩放，右键或中键按住 + 拖拽平移，右键单击复位
- 面包屑中键单击改为在资源管理器中打开目录（原为 Ctrl + 左键）
- 面包屑盘符段不再可点击，避免误触扫描整个磁盘
- 修复面包屑路径拼接产生的驱动器相对路径问题（`C:Users` 型），改为从盘符根开始拼接
- 修复适配窗口缩放按窗口外框（含标题栏）计算导致图片略微溢出的问题
- 修复平移画布后"恢复上次会话"按钮从图片下方露出、且仍可被点击的问题
- 新增 F 键：按当前窗口尺寸重新适配并复位画布
